# Obsidian 插件：标签与复习元数据

现在推荐由 Obsidian 插件提供本机接口。打开 Obsidian 和 Chrome 即可工作，关闭 Obsidian 时端口随插件释放；不需要另外启动 Node 服务。

## 安装与连接

运行 `npm ci` 和 `npm run build:plugin`，把 `.output/obsidian-plugin/main.js`、`manifest.json` 复制到目标笔记库的 `.obsidian/plugins/x-learning-feed/`，在 Obsidian 社区插件设置中启用。默认端口是 `43127`，令牌自动生成。更新扩展时在 `chrome://extensions` 或 `edge://extensions` 中重新加载，然后刷新 X 首页。

1. Obsidian 打开“设置 → X Learning Feed”，确认状态为“运行中”。
2. 复制插件设置中的连接令牌，点击 Chrome 扩展图标，在原页面面板的“连接设置”中填写，端口填 `43127`，点击“连接 Obsidian”。
3. 给文章添加 `#x-feed`；属性区 `tags` 中添加 `x-feed` 也可以。
4. 在 X 首页浏览。来自 Obsidian 的卡片带“Obsidian”来源标记，可展开正文并选择熟悉度。
5. 移除标签后，下次同步会从浏览器缓存及当前卡片中移除这篇文章。正文修改和重命名也会同步。

点击复习后立即自动写回，无需手动同步。约每 30 秒自动接收 Obsidian 的文章变化和重试离线记录；打开网页内面板也会自动检查连接。卡片状态在约 2 秒内更新。第一次给已有页面中的笔记加标签后，可以刷新 X 首页开始新一轮展示。

网页内面板和设置页已移除手动导入。连接 Obsidian 后只展示当前笔记库的文章；旧导入副本仍保留在本地，不会混入当前信息流。开关和频率修改后直接保存，连接设置在成功连接后默认收起。

插件设置中的“语言”可选跟随 Obsidian、中文或 English。浏览器请求带有扩展当前语言，插件按该语言返回错误信息。

## 属性与冲突

| 属性 | 含义 |
| --- | --- |
| `xfeed_id` | 自动生成的固定身份，文章改名或改正文后保持 |
| `xfeed_review_count` | 复习次数，默认 0 |
| `xfeed_last_reviewed` | 最近复习时间，可清空 |
| `xfeed_remarks` | 复习备注，最多 4000 字符 |
| `xfeed_applied_ops` | 自动保存的操作 ID，用于避免网络重试重复计数 |
| `xfeed_rating` | 熟悉度：1 重来、2 困难、3 良好、4 简单 |
| `xfeed_interval_days` | 上次安排的复习间隔，单位为天 |
| `xfeed_next_review` | 下次复习时间；未到期文章暂不推送 |

选择熟悉度才计数，展开与收起不会计数。复习信息写回属性区；“现场编辑”可修改正文。

X 信息流卡片的四档熟悉度按钮会自动计数、保存熟悉度并安排下次复习，结果写回 Obsidian 原文属性。首次“重来、困难、良好、简单”的间隔分别为 10 分钟、1 天、3 天、7 天；后续按固定倍率增长，使用简化的间隔排程。浏览器的离线评分会自动重试，重复请求不会重复计数。

点击浏览器卡片“在 Obsidian 中打开”，会定位原文并进入编辑模式。保存后，文章与复习属性在下一次自动同步时更新到浏览器，通常不超过 30 秒。打开原文需要 Obsidian 在线；按钮不接收任意文件路径。

复习操作先存入 IndexedDB 队列。断网或 Obsidian 关闭期间显示待同步，恢复连接后依次写回。已写入但响应丢失时，重发同一操作不会重复增加次数。

旧版手动修改复习信息前会记录当前元数据版本；两边同时改动时，插件拒绝覆盖并保留 Chrome 的待处理内容。此时网页内面板才会出现“有修改尚未保存”，显示保留的修改。点击“保留 Obsidian 当前数据”会放弃这次待写回的修改，在 Obsidian 中按最新值调整。正常复习加一会自动合并，无需处理这些提示。操作未确认之前不要清除扩展数据。

如果文章被复制，副本同时带有 `xfeed_id`，插件会报身份冲突。删除副本的 `xfeed_id` 后再同步，插件将为它创建新身份。请勿手动清空 `xfeed_applied_ops`，否则已确认操作的旧请求可能被重复执行。

## 实现与验证

插件只绑定 `127.0.0.1`，请求要求令牌，拒绝普通网站的 Origin。写入接口允许复习记录、添加排除标签的归档操作，以及带正文版本校验的现场编辑，拒绝任意文件路径和未支持的属性。对笔记使用 Obsidian `Vault.process` 原子处理；正文编辑保留属性，复习和归档保留正文。

构建与检查：

```sh
npm run build:plugin
npm run check:plugin
npm run build:extension
npm run check:extension
npm test
```

产物在 `.output/obsidian-plugin`，包含 `main.js` 与 `manifest.json`。手动安装时复制到目标库 `.obsidian/plugins/x-learning-feed/`，然后启用社区插件。插件设置保存在自己的 `data.json`。关闭插件即可关闭本机接口，笔记的属性和浏览器待同步队列保留。

旧版 Node MCP 使用相同端口。使用插件时请停止它；MCP 工具代码仍保留供独立运行，不能和插件同时占用该端口。

测试覆盖写回、重试去重、正文保留与标签移除。网页内面板与时间线需要在真实浏览器中验收。图片仅支持内嵌格式，数学公式未加入专门渲染。

点击浏览器工具栏图标，只在当前 X 页面右上方展开面板，不打开扩展页面或新标签。再点图标、点面板外、点击右上角关闭或按 Esc 即收起。重新加载扩展后需要刷新已有 X 标签，让页面接收新版点击消息。在非 X 页面点击不会跳转；请先打开 X。

## 笔记漫游

需更新 Obsidian 插件和 Chrome 扩展至 0.7.1。X 页内面板开启“笔记漫游”后读取整个 Markdown 笔记库，随机插入未展示的文章；关闭后只保留带 `#x-feed` 标签的文章。漫游文章同样支持复习记录，离线时先保存本地，恢复后自动写回。纯浏览不会修改未标记文章。

0.8.0 的 X 卡片提供展开/收起、点赞/点踩、熟悉度评分、“在 Obsidian 中打开”、“现场编辑”和“归档”。浏览器面板新增标签自选和默认开启的时间权重。如需调整次数、时间或备注，请在 Obsidian 属性区修改。旧版本留下的待写回操作仍会继续处理。

“归档”向原文 `tags` 属性添加 `no-x-feed`，保留已有标签、正文及复习次数；它在标签模式和漫游模式下都会被排除。手动添加内联 `#no-x-feed` 也能排除，代码块与相似标签不会被误判。离线归档先在浏览器隐藏并保存操作，恢复连接后自动写回；网络重试不会重复添加标签。移除文章中的排除标签可恢复展示资格。

现场编辑：在 X 卡片点击“现场编辑”读取原始 Markdown 正文，修改后点击“保存并同步”，或点击“取消”。保存仅修改正文，保留笔记属性。已保存的离线草稿会持久保存在浏览器，恢复连接后自动写回；若 Obsidian 正文已变化，自动写回停止，扩展图标打开的面板会保留并显示草稿。先复制草稿，再放弃冲突操作；重新打开“现场编辑”读取最新正文后，再应用修改。未点击保存的草稿不会写入笔记库。

从 0.7.1 起，文章按正文非空白字数自动降权：字数权重 = 1 / (1 + 字数 / 1000)。1000 字乘以 ½，3000 字乘以 ¼；与点赞和时间权重相乘，标签推送与笔记漫游均适用，关闭时间权重也不会关闭字数降权。统计显示正文的 Unicode 字符，忽略空白、HTML 标记和图片数据；长文仍保留正权重。
