# 真实 x.com 手动验收

状态：此前基础功能已由用户确认正常；本次网页内面板与样式更新待真实浏览器复验。模拟 DOM 与协议测试不能替代以下验收。

0.4.0 卡片提供展开/收起、“已复习 +1”和“归档”。重新加载扩展后检查自动写回、待保存状态及重绘。复习信息可在 Obsidian 属性区调整。参考 [插件说明](obsidian-plugin.md)。

## 准备

1. 执行 `npm test`、`npm run check:extension`。
2. 在 Chrome / Edge 加载 `.output/chrome-mv3`，连接 Obsidian 插件，给至少 3 篇笔记加 `#x-feed` 标签。
3. 设置间隔为 10 并启用，打开登录后的 `https://x.com/home`。保持其他会改变 X 时间线的扩展关闭，以便定位问题。
4. 可选：将本项目接入 MCP 客户端，导入 `notes/example.md`，从 `.data/bridge-token` 复制令牌连接扩展。

## 检查

| 操作 | 通过条件 |
| --- | --- |
| 从首页顶部向下滚动，累计不同推文 | 第 10、20、30 条遇到的推文后出现卡片，广告/推荐模块没有被当成推文；若广告具有真实推文 article，则计为推文 |
| 来回滚动，让旧推文离开并重新进入可见区 | 一张卡片最多显示一份，已分配位置恢复正确，无旧卡片附着到另一条推文 |
| 持续滚动直到用尽笔记 | 卡片数量有上限，不循环相同卡片，滚动保持顺畅，无跳跃、重叠或空白区 |
| 点击展开、收起、已复习 +1 | 正文展开/收起正常，复习计数自动写回，推文详情不会被误触发 |
| 将频率改成 2 后刷新页面 | 每遇到 2 条新推文分配一张笔记，设置与笔记保持保存 |
| 切换首页标签、进入个人页或推文详情，再返回 | 非首页没有卡片，首页恢复，无控制台未捕获错误 |
| 关闭学习开关 | 约 2 秒内移除所有学习卡片，原推文仍可正常操作 |
| 在扩展管理页面禁用扩展 | 当前页面卡片清理；若浏览器停止脚本而没有触发清理，刷新后应完全恢复原信息流 |
| 重新启用扩展并刷新 | 笔记与设置仍存在 |
| 点击扩展工具栏图标 | 当前 X 页面右上方展开面板，地址仍为 x.com，不开新标签；无手动导入、保存设置或立即同步按钮 |
| 修改开关与频率后关闭弹窗，再打开 | 自动保存，设置保持；连接设置默认收起 |
| 点击“已复习 +1”，随后再点一次 | 自动写回 Obsidian，两次共增加 2；无需点击同步 |
| 检查卡片操作区 | 显示展开/收起、已复习 +1、归档，无跳过或修改复习信息表单 |
| 点击归档后刷新并切换模式 | 原文添加 no-x-feed 标签，卡片立即消失；标签模式和漫游模式都不再出现 |
| 离线归档，刷新后重新打开 Obsidian | 本地持续隐藏，恢复后自动添加标签，原有正文、标签及复习次数保留 |
| 手动添加与移除 no-x-feed 标签 | 添加后在两种模式都排除，移除后恢复资格；代码块内文字不作为标签 |
| Obsidian 关闭时复习，再重新打开 | 先保存本地，恢复后约 30 秒内自动写回；记录不重复 |
| 两端同时修改元数据 | 只有实际写回失败时出现待处理提示，保留修改内容，不覆盖 Obsidian 新数据 |
| 在 Obsidian 添加或移除标签 | 定时自动接收变化，最长约 30 秒；打开弹窗也会自动检查 |
| 开启“笔记漫游”并滚动 | 无标签文章也能出现，选择随机，本轮不重复；仍遵守插入频率 |
| 漫游中点击无标签文章的复习按钮 | 自动写回复习属性，正文与标签保持原样，重试不会重复计数 |
| 关闭“笔记漫游” | 当前无标签卡片移除，恢复只展示 #x-feed 文章 |
| 关闭 Obsidian 后刷新 X | 使用 IndexedDB 中的已同步笔记，重新打开后自动恢复 |

## 恶意 HTML 检查

将以下内容放进带 `#x-feed` 标签的测试笔记，或保存为 `unsafe.html` 使用独立 MCP 导入。打开卡片后，应仅看到安全正文及链接文字，没有弹窗、嵌入网站或外部图片请求；X 样式不改变。

```html
<h1>安全检查</h1>
<p onclick="alert('event')" style="position:fixed;inset:0">安全正文</p>
<script>alert('script')</script>
<img src="https://example.invalid/tracker" onerror="alert('image')">
<a href="javascript:alert('link')">链接文字</a>
<iframe src="https://example.invalid/"></iframe>
<svg onload="alert('svg')"></svg>
```

浏览器开发者工具中检查 Console 和 Network。记录浏览器版本、X 首页标签、卡片数量、滚动是否跳跃以及错误。X 的 DOM 与虚拟列表会变化，如果出现重叠或卡片不显示，应停止使用并针对实际页面调整 `lib/timeline.ts`。

网页内面板回归：再点图标、点面板外、点击关闭、按 Esc（包括输入框内）都应收起；连续开关只能出现一个面板。面板外仍可正常滚动和点击推文。窄窗口面板不超出屏幕。
